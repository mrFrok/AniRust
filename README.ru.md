# AniRust

Кроссплатформенный десктопный клиент Anixart на Rust и Slint, с полноценным
плеером на mpv.

*[English version](README.md)*

> AniRust — неофициальный проект, **не аффилированный** с разработчиками
> Anixart. Название и оформление Anixart принадлежат их владельцам.

## Зачем

Официальный клиент существует только под Android, закрыт и с рекламой.
AniRust — десктопный клиент с собственным плеером: своя скорость
воспроизведения, нормальный рендер субтитров, аппаратный декод, апскейл
Anime4K, продолжение с нужного места и синхронизация прогресса с аккаунтом
Anixart.

## Состояние

Рабочее. Открываете каталог или ищете по названию, заходите в релиз, выбираете
озвучку и серию — и смотрите прямо на экране релиза, а не на отдельном экране
плеера: чтобы выбрать следующую серию, не нужно уходить с того, что смотрите.

Работает:

- **Каталог** — что смотрят сейчас и поиск по названию.
- **Воспроизведение** — Kodik, AniLibria и Sibnet разрешаются в прямые потоки;
  аппаратный декод; выбор качества, скорости, звуковой дорожки и субтитров;
  апскейл Anime4K и интерполяция кадров; пропуск опенинга.
- **Продолжение** — место, где остановились, запоминается, список открывается
  на нужной серии, а после окончания включается следующая.
- **Аккаунт** — вход синхронизирует просмотренные серии и историю; токен
  хранится в системном хранилище секретов. Экран профиля показывает сам
  аккаунт: кольцо по спискам, счётчики активности и просмотренное недавно —
  и каждое из этого открывает список или релиз за ним.
- **Оформление** — светлое, тёмное, AMOLED или как в системе; выбирается на
  экране профиля и хранится в `~/.config/anirust/settings.json`.

Не покрыт SovetRomantica: его хост недоступен из сети, на которой всё это
делалось, поэтому протокол снять не удалось — а угадывать значило бы читать
чужую реализацию. Allvideo, StudioMir, Myvi, VKVideo, OK, RuTube и MailRu
перечислены в официальном клиенте, но в выборке каталога не встретились.

Дальше: собранные сборки.

## Сборка

Нужен Rust 1.90+ и, для плеера, `libmpv` >= 2. В Debian и Ubuntu это
`libmpv-dev`, в Arch — `mpv`.

```sh
cargo build --release
./target/release/anirust            # каталог
./target/release/anirust 2999       # сразу в релиз
```

### Посмотреть интерфейс без экрана

Ошибки вёрстки легко сделать и трудно заметить на словах. Интерфейс рисуется в
PNG программным рендерером, без оконного сервера:

```sh
cargo run -p anirust-gui --example screenshot -- out.png 1440 900 release
```

Последний аргумент — `home`, `home-signed-in`, `home-hover-account`,
`release`, `playing`, `theatre`, `downloads`, `sign-in`, `failed`, `saved`,
`loading`, `refreshing`, `empty`, `nothing`, `profile`, `profile-signed-in`,
`profile-light`, `profile-en`, `home-downloading`, `light` или `amoled`;
ширина меньше 900 даёт вертикальную раскладку. Состояния за пределами очевидных и есть самые
нужные: каждое — экран, который легко не проверить и легко сделать
неправильно: ещё ничего не загрузилось, ничего не нашлось, включать нечего.

Одно отличие от работающего приложения стоит знать до того, как начнёшь
чинить несуществующий баг: программный рендерер обрезает по прямоугольнику и
игнорирует `border-radius`, поэтому всё, что лежит в скруглённой коробке с
`clip: true`, в PNG имеет квадратные углы, а на экране — скруглённые.

## Зонд

`anirust-cli` дёргает живой API и печатает результат. Диагностика идёт в
stderr, данные — в stdout, поэтому вывод можно направлять в `jq`.

```sh
# Поиск
anirust-cli search "Стальной алхимик"

# Обход всей цепочки воспроизведения и доля серий, которым нужен экстрактор
anirust-cli chain 307 --all-dubbers

# От id релиза сразу до готового потока
anirust-cli stream 307 1

# Готовая команда mpv — заголовки и таймаут уже подставлены
$(anirust-cli stream 307 1 --mpv)

# Хосты, для которых есть экстрактор
anirust-cli hosts

# Аккаунт
export ANIRUST_TOKEN=$(anirust-cli login <логин>)
anirust-cli me
anirust-cli list watching
```

Ноды CDN, на которые редиректят манифесты, бывают очень медленными на
установке соединения — замерено 19 с у хоста, который секундой раньше отвечал
за 14 мс. Дефолтный таймаут ffmpeg короче, поэтому `--mpv` всегда подставляет
`--network-timeout`: без него исправный поток выглядит как сломанный
экстрактор.

## Архитектура

```
api/       типизированный клиент Anixart (reqwest + serde)
extract/   трейт Extractor и реализации по хостам
player/    обёртка libmpv, рендер в GL-текстуру Slint
gui/       приложение на Slint
cli/       отладочный зонд
```

mpv рисует в фреймбуфер, которым владеет GUI, а Slint берёт его как текстуру —
ни один кадр не проходит через процессор. Две детали стоили по долгому вечеру
каждая, и о них стоит знать до того, как трогать `gui/src/video.rs`: перерисовку
окна нужно гнать из `AfterRendering`, а не по таймеру, иначе mpv неверно
оценивает частоту экрана и интерполяция рвёт картинку; и промежуточные буферы
`rgba16f`, которые mpv выбирает по умолчанию, непригодны в контексте OpenGL ES,
который даёт Slint, — это проявляется полосами рваного цвета, а не ошибкой.

Путь от релиза до воспроизведения — три запроса и, как правило, экстрактор:

```
dubbers(release_id)                        -> озвучки
sources(release_id, dubber_id)             -> Kodik, Sibnet, ...
episodes(release_id, dubber_id, source_id) -> серии
```

Каждая серия несёт `url` и флаг `iframe`. Замер по 832 сериям из 8 релизов:
эмбедов 97%, и 96% из них приходится на Kodik.

**Флагу `iframe` доверять нельзя.** Серии Sibnet и AniLibria приходят с
`iframe = false`, хотя их ссылки (`shell.php?videoid=`, `iframe.php?id=`) —
страницы плеера, отдающие `text/html`. Поэтому решение принимается по хосту:
если для него есть экстрактор, ссылка идёт через него независимо от флага.

## Чистая комната

Слой API и экстракторы написаны по **наблюдаемому поведению протокола**, а не
по декомпилированным исходникам официального приложения. Это осознанное
ограничение, и оно соблюдается буквально:

1. Декомпилированный материал никогда не попадает в репозиторий — см.
   `.gitignore`.
2. Из официального приложения берутся только факты интерфейса: хост, путь,
   метод, имя поля, значение enum. Это факты, а не форма выражения.
3. Реализация пишется против живого обмена, а не против чужого кода.
4. Фикстуры тестов — сохранённые HTTP-ответы, не чужие исходники.
5. mpv, ffmpeg и шейдеры Anime4K берутся из апстрима, не из APK.
